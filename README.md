# Slay the Switch

A lightweight roguelike deckbuilder for Nintendo Switch, inspired by Slay the Spire.

## Overview

Slay the Switch is a simple deckbuilder where each run has you moving through a branching map, fighting enemies, and building your deck over time. The focus is on quick runs and a clean gameplay loop that’s easy to pick up and play.

## Features

* Roguelike deckbuilder gameplay
* Turn-based combat with energy, damage, block, and status effects
* Card system with attacks, skills, upgrades, and exhaust mechanics
* Randomized map with branching paths
* Normal, elite, and boss encounters
* Shops and campfires
* Card rewards and upgrades
* Endless mode
* Run stats tracking (floors, coins, enemies defeated)
* Player classes (crawlers) with different starting stats
* Controller and touchscreen support

## Controls

A — Confirm / Play Card
B — Back / Skip
X — End Turn

D-Pad — Move Selection
Up / Down — Change Target

L / R — Switch Target
ZL / ZR — Switch Target

Touch — Tap cards, enemies, and UI

## Installation

1. Download the latest release from the Releases page
2. Place the `.nro` file into your `/switch/` folder on your SD card
3. Launch from the Homebrew Menu
